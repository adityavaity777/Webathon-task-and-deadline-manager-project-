# ✅ TaskFlow — Master your deadlines

A polished, modern, fully responsive **task and deadline manager** built with pure HTML, CSS, and vanilla JavaScript. No frameworks, no build tools, no backend — just open `index.html` and go.

Built for **Webathon 2026**.

## Features

- **Create, edit, delete tasks** — modal form with inline validation
- **Priority levels** — High / Medium / Low with visual color coding
- **Deadline tracking** — smart countdown labels ("Due today", "2d overdue") and overdue badges
- **Live search** — filter by title, description, or category instantly
- **Filter tabs** — All / Pending / Completed / Overdue with live counts
- **Sorting** — by due date, priority, recently added, or title (A–Z)
- **Priority filter** — narrow down by a specific priority level
- **Dashboard** — stat cards + animated progress bar showing completion rate
- **localStorage persistence** — your tasks survive page reloads
- **Reset demo data** — restore the original 12 sample tasks anytime
- **Toast notifications** — feedback for every action
- **Loading, empty, success, and error states** — all UI states covered
- **Fully responsive** — mobile (360px), tablet, and desktop with hamburger menu
- **Accessible** — semantic HTML, ARIA labels, focus states, keyboard support (Esc closes modals)

## How to run

1. Download or clone this repository.
2. Open `index.html` in any modern browser.

That's it — no server, no install, no dependencies.
